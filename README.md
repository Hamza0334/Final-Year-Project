# University AI Chatbot System

## Overview
An intelligent multilingual chatbot developed as a Final Year Project for the Sheikh Zayed Islamic Center application. The system was designed to automatically fetch application data, process user queries, and provide instant responses to students and visitors in multiple languages.

The chatbot can understand user questions and respond intelligently based on stored institutional data. It supports English and Roman Urdu responses depending on the user's input language, improving accessibility and user experience.

## Key Features

- AI-powered chatbot for university application assistance
- Real-time question answering based on application data
- English to English responses
- Urdu queries answered in Roman Urdu
- Smart data retrieval and contextual responses
- Fast semantic search using vector database
- User-friendly web interface
- Responsive design using HTML & CSS

## How It Works

1. Application data is fetched and processed.
2. Data embeddings are stored in ChromaDB.
3. User submits a question through chatbot interface.
4. LangChain retrieves the most relevant context.
5. AI model generates an accurate response.
6. Output language adjusts based on user query.
